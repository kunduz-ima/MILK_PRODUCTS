# 🥛 Milk Products - Enterprise Management System

Веб-приложение для автоматизации бизнес-процессов предприятия по производству молочных продуктов. Проект разработан в рамках курсовой работы по дисциплине «Database Management Systems».

## 🛠️ Стек технологий
* **Backend:** C#, ASP.NET Core MVC (.NET 8)
* **Database:** MS SQL Server (Entity Framework Core, ADO.NET)
* **Frontend:** HTML, CSS, JavaScript, Bootstrap, jQuery
* **Библиотеки:** QuestPDF (генерация PDF), DocumentFormat.OpenXml (генерация Word), EPPlus (генерация Excel)
* **Хостинг:** MonsterASP.NET (Web + MS SQL)

## 🚀 Демо (Live Demo)
**Ссылка на работающее приложение:** http://milkproducts.runasp.net

### 🔐 Тестовые аккаунты для входа
Для демонстрации работы системы разграничения прав доступа (RBAC) вы можете войти под следующими пользователями:

| Роль | Логин (Username) | Пароль (Password) | Доступный функционал |
| :--- | :--- | :--- | :--- |
| **Администратор** | `Admin` | `adm123` | Полный доступ ко всем разделам и операциям |
| **Директор** | `Director` | `dir123` | Просмотр всех данных, выдача зарплат, генерация отчетов |
| **Технолог** | `Technologist` | `tech123` | Управление сырьем, ингредиентами и производством |
| **Бухгалтер** | `Accountant` | `acc123` | Управление бюджетом, кредитами, платежами и зарплатами |
| **Менеджер** | `Manager` | `man123` | Закупка сырья, управление готовой продукцией и продажами |

## ✨ Ключевые возможности
* **Разграничение прав доступа (Identity & Roles):** 5 ролей с разными уровнями доступа к контроллерам и представлениям.
* **Управление производством:** Учет сырья, создание рецептур (ингредиентов), производство готовой продукции.
* **Финансовый учет:** Контроль бюджета, учет кредитов, расчет и выплата заработных плат (с учетом бонусов).
* **Генерация отчетов:** Экспорт данных о производстве, продажах, закупках и зарплатах в форматы **Excel, Word и PDF**.
* **База данных:** 15 таблиц, 7 хранимых процедур и 3 триггера для автоматизации сложных вычислений (например, списание остатков при продаже).

## 🗄️ Структура базы данных
В проекте реализована сложная реляционная база данных, включающая:
* Учет кадров (`Employees`, `Positions`, `Salaries`)
* Складской учет (`RawMaterials`, `FinishedProducts`, `Ingredients`)
* Операции (`Purchases`, `Productions`, `Sales`)
* Финансы (`Budgets`, `Credits`, `Payments`)

## 💻 Как запустить локально
1. Клонируйте репозиторий:
   `git clone https://github.com/ваш-username/MilkProducts.git`
2. Откройте файл `MILK_PRODUCTS.sln` в Visual Studio 2022.
3. Создайте базу данных в MS SQL Server (восстановите из бэкапа или примените скрипты).
4. В файле `appsettings.json` укажите вашу строку подключения к локальной базе данных в разделе `ConnectionStrings`.
5. Запустите проект (F5).
